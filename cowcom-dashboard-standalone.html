Domain Flow

cowcom.my가 실제로 연결되는 방식

  1. 대시보드 코드를 GitHub에 올립니다.
  2. Vercel이 코드를 인터넷에 배포합니다.
  3. Gabia DNS에서 cowcom.my를 Vercel 주소로 연결합니다.
  4. 스마트폰에서 https://cowcom.my 로 접속합니다.
