프로젝트 비전

사용자가 직접 만들거나 템플릿에서 선택한 개인 식사 룰에 실제 음식 데이터(칼로리, 가격)를 결합해 즉시 판단 + 미래 효과를 보여주는 도구.

그냥 AI한테 매번 물어보는 게 아니라, 내 규칙 + 내 데이터 + 계산된 임팩트를 한 번에 제공한다.

기존 문제
매번 규칙 설명 + 칼로리 계산 + 비용 추정 별도
제공하는 가치
한 번 입력 → 규칙 매칭 + 칼로리/비용 + 다이어트 효과 한 번에
차별화 포인트
지속적인 개인 룰 + 누적 데이터 기반 예측
핵심 원칙
템플릿 우선
사용자가 처음부터 모든 룰을 만들지 않게
데이터 결합
칼로리 + 금액 + 효과를 즉시 계산
새로운 가치
무료 AI보다 개인화되고 계산된 결과 제공
수익화 중심
가치가 명확할 때만 돈 받음
무료 AI와의 차별화 (수익화의 핵심)
무료 AI (ChatGPT 등)
  • • 매번 규칙을 다시 설명해야 함
  • • 칼로리·가격 계산을 매번 물어봐야 함
  • • 내 과거 식사 기록을 기억하지 못함
  • • "이번 달 따라가면 어떻게 될까?" 예측 어려움
  • • 일관성 없음 (기분에 따라 답변 달라짐)
Food Rule Guard
  • • 한 번 만든 룰이 영구적으로 적용
  • • 템플릿 + 음식 DB로 계산 자동화
  • • 내 결정 로그를 쌓아 개인화된 예측
  • • "이 규칙 지키면 30일 후 -2.3kg / 87,000원 절감" 즉시 제시
  • • 내 기준으로 일관되게 판단
제품 컨셉
Food Rule Guard = 규칙 엔진 + 템플릿 라이브러리 + 음식 데이터 + 임팩트 계산기
1. 개인 룰 시스템
사용자가 만들거나 템플릿에서 가져온 룰을 영구 저장. 매 입력마다 자동 적용.
2. 템플릿 라이브러리
다이어트, 예산 관리, 야식 금지, 건강 중심 등 바로 사용할 수 있는 미리 정의된 룰 세트 + 데이터.
3. 데이터 + 계산 레이어
음식 칼로리, 평균 가격, 영양 정보. 결정 시 즉시 칼로리/비용 계산 + 장기 효과 시뮬레이션.
주요 기능 (MVP + 확장)
기본 기능 (무료 티어)
  • • 템플릿 선택 (다이어트 / 예산 / 야식금지 등 8~10종)
  • • 텍스트 입력으로 즉시 판단 (규칙 매칭)
  • • 기본 칼로리·가격 표시 (시드 데이터)
  • • 간단 결정 로그 (참음/먹음)
  • • 내 룰 추가/수정
유료 차별화 기능
  • • 상세 음식 데이터베이스 (더 많은 음식 + 영양소)
  • • 30일 / 90일 임팩트 시뮬레이션 (칼로리 절감 → 체중 변화, 비용 절감)
  • • 개인 패턴 분석 ("스트레스 받을 때 이 규칙 위반률 64%")
  • • 고급 룰 (조건 조합, 시간대별, 이전 식사 연동)
  • • 리포트 내보내기 + 알림
  • • 클라우드 동기화 (멀티 기기)
템플릿 예시 (AI 없이 바로 시작 가능)
체중 감량 모드
기본 1,800kcal 목표
  • • 저녁 8시 이후 아무것도 먹지 않는다
  • • 배달은 주 2회 이하
  • • 탄수화물 위주 식사 후 디저트 자제
예산 관리 모드
외식 월 15만 원 이하
  • • 배달 1회당 15,000원 이상 금지
  • • 카페 음료는 주 3회 이하
  • • 장보기 전 리스트 작성 후 구매
야식 완전 금지
수면 + 다이어트 특화
  • • 오후 9시 이후 음식 섭취 금지
  • • 배고픔이 7 이상일 때만 물 먼저 마신다
  • • 스트레스 시 단 음식 대체 음식 준비
→ 사용자는 템플릿을 그대로 쓰거나, 일부만 수정해서 시작할 수 있음 (AI로 처음부터 만드는 피로 감소)
데이터 & 계산 레이어 (새로운 가치의 핵심)
포함할 데이터
  • • 한국인 주요 음식 칼로리 (치킨, 피자, 라면, 삼겹살, 김치찌개 등)
  • • 1인분 기준 평균 가격 (배달앱 평균가 반영)
  • • 간단 영양 정보 (단백질/탄수/지방 대략)
  • • 사용자 커스텀 음식 추가 가능
제공할 계산/예측
  • • 이번 결정 칼로리 + 예상 비용
  • • "이 규칙을 30일 지키면 예상 절감 칼로리 / 비용 / 체중 변화"
  • • 실제 로그 vs 목표 비교
  • • 위반 패턴 분석 (요일, 시간, 감정별)
주의: 모든 계산은 "추정치"이며 의학적 조언이 아님. 명확히 고지.
개발 로드맵
Phase 0 완료
Food Guard Mini (현재)
순수 클라이언트, 기본 룰 매칭, localStorage, 서버 비용 0원. 개념 검증용.
Phase 1 2~3주
템플릿 + 데이터 베이스
  • • 8~10개 실용 템플릿 제작
  • • 150~200개 한국 음식 시드 데이터 (칼로리 + 가격)
  • • 음식 검색/선택 UI
  • • 결정 시 칼로리·비용 즉시 표시
기본 계산 엔진
  • • 단순 칼로리 합산
  • • 월간 비용 추정
  • • 로그 기반 간단 통계
  • • 사용자 커스텀 음식 등록
Phase 2 2~3주
임팩트 시뮬레이션
  • • 30일 / 90일 예측 (칼로리 절감 → 체중 변화 모델)
  • • 비용 절감 리포트
  • • "이대로 가면" vs "규칙 지키면" 비교
  • • 시각화 (차트)
개인화 강화
  • • 실제 로그 기반 위반 패턴 분석
  • • 템플릿 커스터마이징 저장
  • • 더 정교한 룰 매칭 (조건 추가)
Phase 3 3주
스마트 레이어 + 수익화 준비
  • • 선택적 저비용 AI (규칙 해석 보조, 입력 이해)
  • • 클라우드 저장 + 동기화 (유료)
  • • 고급 인사이트 (개인 트렌드)
  • • Freemium 모델 적용
  • • 리포트 내보내기 / 알림
  • • 실제 유료 전환 테스트
수익화 모델

유료 (월 4,900원)
전체 데이터 + 임팩트 예측 + 무제한 로그 + 고급 분석
연간
2개월 무료 (월 약 4,000원)
사용자가 돈 낼 이유
• "이 규칙대로 가면 실제로 얼마 아끼고 얼마나 빠질까"를 숫자로 바로 보고 싶어서
• 매번 AI한테 설명하는 피로를 없애고 싶어서
• 내 실제 데이터로 맞춤 예측을 보고 싶어서
• 템플릿으로 시작해서 꾸준히 관리하고 싶어서
기술 스택 & 비용 관리
초기 (Phase 0~1)
순수 HTML/JS + Tailwind + localStorage + Vercel 정적 배포
→ 서버 비용 거의 0원
Phase 2 이후
Vercel Functions (선택적) + 저비용 LLM (Gemini Flash 등) + 간단 DB
→ AI 호출은 유료 사용자 위주 + 캐싱으로 비용 통제
주요 위험 및 대처
데이터 정확도
칼로리·가격이 실제와 다를 수 있음
→ "추정치" 명확 고지 + 사용자 수정 기능 필수
의학적 조언 오해
체중 변화 예측이 의학 조언으로 보일 위험
→ 강한 disclaimer + "참고용" 강조
초기 데이터 구축 비용
음식 데이터 직접 넣는 수고
→ Phase 1은 150개 정도로 제한 + 사용자 추가 유도
사용자 유지
다이어트 앱은 이탈률 높음
→ "규칙 위반 즉시 피드백" + 작은 승리 표시로 루프 만들기
