프로젝트 비전

사용자가 직접 만든 개인 룰과 누적된 자신의 행동 데이터를 기반으로 중요한 결정을 도와주는 도구.

단순한 인벤토리 앱이 아니라, 구매 후회 방지와 물건 정리 의사결정에 특화된 개인용 의사결정 보조 시스템.

개발 로드맵 (Phase별)
총 4 Phase
Phase 0 완료
현재
기획 및 초기 프로토타입
개발계획서 작성 • 데이터 모델 정의 • Rule Engine 설계 • 인터랙티브 HTML 프로토타입 제작
→ 이 문서 + PROTOTYPE_STARTER.html 완성
Phase 1 2~3주
공통 기반 구축
  • • 실제 Rule Engine 구현 (Python or JS)
  • • 아이템 CRUD + 기본 룰 매칭
  • • DecisionLog 저장 구조
  • • 간단 로컬 데이터베이스 (SQLite / JSON)
공통 UI 베이스
  • • 룰 관리 화면
  • • 아이템 등록/리스트
  • • 기본 대시보드
  • • 로컬 저장 + 내보내기 기능
Phase 2 2주
Idea 1 - 구매 가드 MVP
핵심 기능
  • • 구매 후보 입력 (텍스트 + 링크)
  • • 즉시 판단 결과 + 이유 표시
  • • 비슷한 아이템 매칭
  • • 구매/스킵 결정 기록
차별화 요소
  • • 사용자가 만든 룰 직접 반영
  • • 개인 사용 패턴 요약
  • • "이번 달 아낀 금액" 추정
Phase 3 2주
Idea 3 - 룰 기반 Declutter MVP
핵심 기능
  • • 자동 소팅된 리스트 (판매추천 / 저사용)
  • • 아이템별 적용된 룰 설명
  • • 판매용 상품 소개 초안 생성
  • • 사용자 피드백 루프
차별화 요소
  • • 사용자가 직접 만든 기준으로 분류
  • • 과거 판매 성공 스타일 반영
  • • 구매 가드와 데이터 연동
Phase 4 2~3주
통합 + 수익화 준비
두 기능 통합 대시보드 • 구독 모델 적용 • 온보딩 개선 • 실제 사용자 테스트 • 보험/자산 연동 준비
기술 스택 추천
Phase 0 ~ 1 초기 빠른 검증
프론트
HTML + Tailwind + Vanilla JS (현재 프로토타입 기반)
데이터 저장
localStorage → SQLite (Python) 또는 JSON 파일
Rule Engine
Python (Pydantic + 간단 evaluator) 또는 JavaScript
Phase 2 이후 본격 개발
추천 스택 1 (웹 + 로컬)
Next.js 15 (App Router) + Tailwind + SQLite + Vercel
추천 스택 2 (로컬 앱)
Tauri + Rust 백엔드 + React 프론트 (프라이버시 최고)
초기는 로컬 중심으로 시작. 클라우드 동기화는 나중에 선택.
수익화 전략 (공통)
가격 모델
  • 무료 월 15회 판단 + 50개 아이템
  • 유료 (월 4,900원) 무제한 + 고급 룰
  • 연간 연 49,000원 (2개월 무료)
설득 포인트
• "이 앱 때문에 구매 포기한 금액" 자동 표시
• "정리 후 실제 판매 수익" 추정 리포트
• 큰 구매나 정리 전에만 사용해도 가치 있음
주요 위험 및 대처 방안
위험: 초기 입력 부담
사용자가 모든 물건을 등록해야 가치가 생김
→ 해결: 카테고리별 최소 등록 유도 + 영수증/구매내역 자동 파싱 (Phase 3~4)
위험: 판단 정확도
AI 판단이 틀리면 신뢰를 잃음
→ 해결: 항상 "사용자가 최종 결정"임을 강조 + 피드백 루프 강하게 설계
